面向园区、建筑与施工现场巡检场景，从 0 到 1 构建以 **3D 自主导航为移动底座**的 M20 Pro 智能巡检系统。系统让机器人能够到达指定楼层和巡检点，并按任务配置触发 **U360 工业雷达实测实量/点云建模**与 **YOLO 视觉安全巡检**，最终形成“任务编排 → 自主到点 → 巡检采集 → 结果汇总与回传 → 异常接管”的完整工程闭环。

> 本仓库是面向招聘与技术交流的**脱敏项目展示页**。完整源码、机器人协议、地图与点云、模型文件、接口字段、网络配置及现场数据均未公开。

## 巡检能力

### 1. U360 工业雷达实测实量与点云建模

机器人到达已配置的扫描点并满足任务准入条件后，任务系统触发 U360 工业雷达执行扫描。系统跟踪设备启动、扫描、分析和完成状态，并对通信重试、启动超时、扫描超时及失败结果进行统一处理。

- **实测实量**：面向施工现场尺寸、距离、高度等测量任务，将测量项、巡检位置与雷达结果关联，支持结果判定和汇总。
- **点云建模**：在目标位置采集空间点云，用于现场三维记录、环境复核和后续测绘分析。
- **自动与手动模式**：既可由航点任务自动触发，也可在机器人静止且设备空闲时执行受控的手动扫描。
- **结果闭环**：扫描产物与楼层、房间、任务和巡检点关联，经过状态确认后进入 Web 监理端并回传业务平台。

### 2. YOLO 视觉安全巡检

系统在机器人端侧使用 RK3588 与 RKNN 部署 YOLOv8 检测链路。视觉模型按任务启停，避免长期占用计算资源；发现现场安全事件时，系统保留类别、置信度、时间和图像证据，并将告警结果交给监理平台统一展示。

公开展示覆盖的典型事件包括：未戴安全帽、人员跌倒和火灾等。视觉检测与导航任务解耦，模型异常不会直接影响底盘控制，巡检告警也不能绕过安全层向机器人下发动作。

### 3. 巡检任务编排与结果管理

每个任务由楼层、房间、巡检点和巡检动作组成。机器人先完成地图与定位准入，再自主导航到点；到点后根据配置执行视觉检测、雷达实测实量或点云建模，待结果确认后继续下一个巡检点。Web 端统一展示机器人状态、任务进度、导航路径、雷达扫描状态、测量结果和视觉告警，并支持失败停止与人工接管。

## 关键工程问题

### 1. 定位失效时如何阻止错误任务下发

任务创建、任务启动和地图切换不能共用一次静态检查。系统在关键状态转换处重新检查地图身份、定位状态、位姿时效和导航后端准备度；任一条件不满足时阻止目标进入运动链路，并保留人工重定位与安全接管入口。

### 2. 多个控制源如何避免同时抢占机器人

导航、楼梯步态、遥操作和急停统一经过控制权仲裁。高优先级安全事件可以使当前任务失效，清除未执行指令并切换到受控停止状态，避免过期动作在任务取消后继续执行。

### 3. 3D 点云为什么需要专门优化

高频点云的重复转换、序列化与前端传输会同时占用 CPU 和内存。项目通过降低无效复制、按用途拆分数据、控制更新频率并缓存可复用结果，使点云链路在保留导航与可视化能力的同时满足长期运行要求。

### 4. 为什么巡检不能简单地“导航到点后调用一次设备”

导航成功只代表机器人到达目标附近，不代表扫描条件已经满足。系统还需要确认机器人静止、当前位姿与巡检点对应、雷达设备空闲、任务未被取消，并持续跟踪扫描和分析状态；只有结果完整且与当前任务匹配时才能继续，否则可能出现重复扫描、结果串任务或机器人尚未停稳就开始测量。

## 系统模块

| 模块 | 职责 |
| --- | --- |
| 感知与点云 | 多源点云接入、过滤、坐标变换与地图数据组织 |
| 地图与定位 | 地图资产、楼层身份、初始位姿、重定位和位姿稳定性检查 |
| 导航与任务 | 路径规划、航点任务、进度管理、取消、失败恢复与跨楼层状态机 |
| 控制安全 | 导航/遥操作仲裁、速度约束、超时保护、急停和任务失效机制 |
| 监理平台 | 地图、点云、路径、机器人状态、任务进度和告警可视化 |
| 雷达测绘 | U360 任务触发、实测实量、点云建模、设备状态、超时重试与结果关联 |
| 视觉巡检 | YOLOv8/RKNN 端侧检测、任务启停、现场安全事件识别与图像留证 |
| 巡检编排 | 航点到达、检测触发、结果确认、任务续接、失败停止与统一结果汇总 |

## 与 VLA 项目的关系

本项目负责真实机器人导航、任务执行和安全控制；语言条件 ObjectNav 与多模态策略研究位于独立仓库：

- [M20 Pro 多模态 VLA 导航与具身控制](https://github.com/ghw1048040694/m20pro-vla)

两部分通过受控的高层任务/运动接口连接，VLA 策略不能绕过定位准入、控制仲裁和底层安全约束直接写入机器人执行器。
